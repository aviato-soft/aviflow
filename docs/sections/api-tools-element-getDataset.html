AviFlow.tools.element.getDataset(element)

AviFlow.tools.element.getDataset(element: HTMLElement) -> Object

Merged dataset of the element and its data-parent chain.
The element's own values win. data-parent holds a CSS selector, resolved first with parentElement.closest(selector), then document.querySelector(selector).
The chain is resolved iteratively with cycle protection; invalid selectors log a warning and stop the chain.
