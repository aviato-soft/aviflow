register(name, actionFn)

register(name: string, actionFn: Function) → AviFlow register(actions: Object) → AviFlow

Chainable, adds one action, or every function of an object.
Invalid arguments log a warning.
Register actions before init() reaches elements that use them.

const flow = new AviFlow();
flow.register('save', async function (flow) { /* this = element */ })
    .register({ a() {}, b() {} });
