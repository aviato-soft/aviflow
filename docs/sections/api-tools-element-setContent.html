setContent(element, content)

AviFlow.tools.element.setContent(element, content) -> HTMLElement | null

Replaces content according to element type:

  • Node -> replaceChildren(clone).
  • input / textarea / select / form-associated custom element -> sets value. A file input accepts only ''; anything else logs a warning and is ignored.
  • HTML -> innerHTML (through sanitizer).
  • Text -> textContent.
