AviFlow.tools.text

String helpers (class AviText, exposed as AviFlow.tools.text). Non-string input to toCamelCase returns ''.

AviFlow.tools.text.toCamelCase(text, firstLetterLower)

AviFlow.tools.text.toCamelCase(text, firstLetterLower = true) -> string

Trims, removes leading -, _, whitespace, and uppercases the letter following each separator run. firstLetterLower = false gives PascalCase.

AviFlow.tools.text.toCamelCase('pending-class')   // "pendingClass"
AviFlow.tools.text.toCamelCase('my_var name')     // "myVarName"
