Overview[cite: 1]

AviFlow is a lightweight zero-dependency JavaScript utility that wires up behavior directly in your markup.[cite: 1] Add a data-flow attribute to any element, and AviFlow binds the event, runs the named action, and delivers the result to the target you specify, with no glue code required.[cite: 1]

Features[cite: 1]

  • Declarative: behavior lives in HTML, next to the element it affects.[cite: 1]
  • Simple grammar: one -> delimiter, at most three parts.[cite: 1]
  • Event modifiers: .prevent and .stop built in.[cite: 1]
  • Sync or async actions: any function can be an action, including async ones.[cite: 1]
  • Extensible: register your own actions with a single call.[cite: 1]
  • Scoped initialization: bind a whole document or just a freshly inserted fragment.[cite: 1]
  • Strict validation: malformed flows are logged as warnings and never registered.[cite: 1]
  • Micro-sized & Dependency-free: Written in pure, modern vanilla JavaScript.[cite: 1]

Installation[cite: 1]

The quickest way to try AviFlow, with no build step. Add the minified build to your page:[cite: 1]

<script src="https://cdn.jsdelivr.net/npm/aviflow@2.0.0/dist/aviflow.min.js" crossorigin="anonymous"></script>

Or install the package from the npm registry:[cite: 1]

npm i aviflow
