AviFlow.tools.element.setActiveContent(element, activeName, opt)

AviFlow.tools.element.setActiveContent(element, activeName, opt = {}) -> HTMLElement | null

Shows the descendants [data-content="name"] listed in activeName and hides all others (tabs, steps, views).
Hidden elements get the hidden class and aria-hidden="true"; shown ones lose both. Note that all [data-content] descendants are affected, including nested ones.

ParamDescription
activeNameString ('a'), space/comma list ('a b', 'a, b'), number, or array. Empty string/array hides all. null/undefined leaves everything unchanged.
opt['hidden-class']Default 'hidden'; several classes allowed; false = none.
opt['hidden-aria']Default true.

Options can also come from data-opt-* attributes on the container; opt wins.

Avoid aria-hidden on focusable descendants: use a hidden class with display:none, or set hidden-aria to false.
