AviFlow.action

AviFlow.action.fetch(element, event?, targetSelector?, flow?)

AviFlow.action.fetch(element: HTMLElement, event?: HTMLEvent | null, targetSelector: string, flow: AviFlow instance) → Promise<Object|string> | null

Registered by default as AviFlow.action.fetch. Reads configuration from the element and performs an HTTP request. Returns null if element is falsy.

Element configuration

SourceUse
data-urlRequest URL (default /).
data-methodHTTP method (default POST, upper-cased).
data-param-* + form fieldsParameters, via AviFlow.tools.element.getParams. Inherited through data-parent.
data-opt-pending-*Pending-state options, see togglePendingState.

opt is spread over the internal request options (headers, method, params, url, …), so it can override any of them.

Request behaviour

  • Always sends X-Requested-With: XMLHttpRequest.
  • GET / HEAD: params are appended to the URL query string.
  • POST / PUT: params are sent as FormData.
  • Other methods: params sent as JSON body with Content-Type: application/json; charset=UTF-8.
  • The element is put in pending state during the request and restored in finally.

Response handling

ResponsePromise
Content-Type contains text/htmlResolves with the response text (string).
Otherwise parsed as JSON with success truthyResolves with the parsed object.
JSON without successRejects with data.error or "[AviFlow.action.fetch] Error fetching data".
Network / parse errorRejects with the original error.

HTTP status codes are not checked; only the body is inspected.
