Example: Fetch Action Parameters

[Event] -> fetch -> [Target]

data-flow="fetch -> #output-14"

data-flow="fetch -> #output-14" is an abreviation for data-flow="click -> fetch -> #output-14"

<button
  data-flow="fetch -> #output-14"
  data-method="post"
  data-param-body="bar"
  data-param-id="101"
  data-param-title="foo"
  data-param-user-id="1"
  data-url="https://jsonplaceholder.typicode.com/posts">Load User Info</button>
