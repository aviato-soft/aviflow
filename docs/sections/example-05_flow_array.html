Example: Multiple flows per element

[Event -> Action -> Target][Event -> Action -> Target][...]

Button A: the same Event and Action, different Target

data-flow="[click -> getTriggerName -> #output-5-1][click -> getTriggerName -> #output-5-2]"

Click on Button A will fill output 1 with:"Trigger name: Button A" and output 2 with:"Trigger name: Button A"

Button B: the same Event and Target, different Action

data-flow="[click -> getTriggerName -> #output-5-1][click -> getTriggerId -> #output-5-1]"

Click on Button B will fill output 1 with:"Trigger name: Button B" and then output 1 will be overwritten with:"Trigger id: button-b"

Button C: the same Action and Target, different Event

data-flow="[click -> trigggetTriggerName -> #output-5-1][dblclick -> getTriggerName -> #output-5-1]"

Click on Button C will fill output 1 with:"Trigger name: Button C" or double click on fill output 1 with:"Trigger name: Button C"

Button D: 2 flows total different Event, Action, Target

data-flow="[click -> trigggetTriggerName -> #output-5-1][dblclick -> getTriggerId -> #output-5-2]"

Click on Button D will fill output 1 with:"Trigger name: Button D" and double click on fill output 2 with:"Trigger id: button-d"

<button name="Button A" id="button-a" data-flow="[click -> getTriggerName -> #output-5-1][click -> getTriggerName -> #output-5-2]">Button A</button>
<button name="Button B" id="button-b" data-flow="[click -> getTriggerName -> #output-5-1][click -> getTriggerId -> #output-5-1]">Button B</button>
<button name="Button C" id="button-c" data-flow="[click -> getTriggerName -> #output-5-1][dblclick -> getTriggerName -> #output-5-1]">Button C</button>
<button name="Button D" id="button-d" data-flow="[click -> getTriggerName -> #output-5-1][dblclick -> getTriggerId -> #output-5-2]">Button D</button>

<script>
  const flow = new AviFlow({
    triggerId: (element) => {
      const elId = element.getAttribute('id');
      return `click trigger with id: ${elId}`;
    },
    triggerName: (element) => {
      const elName = element.getAttribute('name');
      return `click trigger with name: ${elName}`;
    }
  });
