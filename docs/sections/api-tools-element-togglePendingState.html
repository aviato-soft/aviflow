AviFlow.tools.element.togglePendingState(element, isPending, opt)

AviFlow.tools.element.togglePendingState(element, isPending = null, opt = {}) -> HTMLElement|SVGElement | null

true = enter pending, false = restore, null = toggle. Only what was changed is restored, using the values saved at entry. Entering twice is a no-op. Tip: call with false in a finally block.

OptionDefaultEffect
pending-class'pending'Class(es) added.
pending-opacity0.6Inline opacity; false disables.
pending-pointer'none'pointer-events; false disables.
pending-disabledtrueDisables form controls (INPUT, BUTTON, SELECT, TEXTAREA, FIELDSET, or anything with a disabled property).

Also sets aria-busy="true" while pending and restores its previous value afterwards. Options come from data-opt-pending-* attributes, overridden by opt. "Off" values are false, 'false', null, undefined.
