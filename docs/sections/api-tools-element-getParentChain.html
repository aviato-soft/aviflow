AviFlow.tools.element.getParentChain(element)

AviFlow.tools.element.getParentChain(element) -> HTMLElement[]

Resolves the data-parent chain of an element and returns it as an array ordered root ancestor first, element last. This is the same chain used by getDataset and getParams to inherit data-* attributes, and by the fetch action to find the nearest parent <form>.

ParamDescription
elementThe element to start from. Returns [] when it is null, undefined or not an element.

Resolution order

  1. The element itself is always part of the chain (last item). Without data-parent the result is [element].
  2. data-parent is a CSS selector. It is matched first against the closest ancestor (parentElement.closest(selector)), nearest first.
  3. If no ancestor matches, the first match in the document is used (document.querySelector(selector)), so the parent does not have to contain the element.
  4. The parent's own data-parent is then followed in the same way, until an element has none.

Safety

  • Cycles (a points to b, b points to a) are detected: each element appears once and the walk stops.
  • A selector that matches nothing ends the chain at the last element found.
  • An invalid selector logs a warning and ends the chain at the last element found. It never throws.
<form action="/users" method="post">
  <select id="color" data-parent="form">...</select>
</form>
AviFlow.tools.element.getParentChain(color)   // [form, select#color]
AviFlow.tools.element.getParentChain(form)    // [form]

<div id="panel"></div>
<button id="btn" data-parent="#panel"></button>
AviFlow.tools.element.getParentChain(btn)     // [div#panel, button#btn]  (document fallback)
