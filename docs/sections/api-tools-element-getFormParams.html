AviFlow.tools.elementgetFormParams(element, useClosest)

AviFlow.tools.element.getFormParams(element, useClosest = false) -> Object<string, string|File|Array>

Reads FormData of a form into an object.
Duplicate field names become arrays.
A key named __proto__ is skipped.
Non-form elements return {} unless useClosest is true, in which case element.form or the closest ancestor <form> is used.
