Example: Fetch using form values for fetch parameters

[Event] -> fetch -> [Target]

data-flow="fetch -> #output-16"

data-flow="fetch -> #output-16" is an abreviation for data-flow="click -> fetch -> #output-16"

<form 
    method="post" 
    action='https://jsonplaceholder.typicode.com/users' 
    data-flow="submit.prevent -> fetch -> #output-16">
  <p><label for="user-id">User id:</label><input type="text" id="user-id" name="user-id"></p>
  <p><label for="title">Title:</label><input type="text" id="title" name="title"></p>
  <p><button type="submit">Submit button</button></p>
</form>
