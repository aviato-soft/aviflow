AviFlow.tools.element.sanitizer

AviFlow.tools.element.sanitizer: ((html: string) => string) | null = null

Optional hook applied to every HTML string inserted by setContent / appendContent.

AviFlow.tools.element.sanitizer = (html) => DOMPurify.sanitize(html);
Without a sanitizer, server HTML is inserted as-is. Set one when responses may contain untrusted markup.
