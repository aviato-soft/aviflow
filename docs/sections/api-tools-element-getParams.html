AviFlow.tools.element.getParams(element, prefix, opt)

AviFlow.tools.element.getParams(element, prefix = 'param', opt = {}) -> Object

Collects data-{prefix}-* attributes (prefix stripped; attribute names, so lowercase/kebab-case) plus form fields.

ParamDescription
prefixDefault param. Some characters like - are stripped.
opt.parentInclude the data-parent chain. Default true.
opt.formInclude form fields. Default true.

Priority (highest first)

  1. data-{prefix}-* of the element
  2. …of each ancestor, nearest first
  3. Form fields of the element and ancestors that are themselves <form>, nearest first
<button data-param-id="7" data-param-sort="asc" data-opt-pending-class="busy">
AviFlow.tools.element.getParams(btn)          // { id: "7", sort: "asc" }
AviFlow.tools.element.getParams(btn, 'opt')   // { "pending-class": "busy" }
