AviFlow.tools.element

Static DOM utilities (class AviElement, exposed as AviFlow.tools.element).
Convention: methods that act on an element return it, or null if the input is not a valid element.
Getters return plain objects ({} when empty).

AviFLow.tools.element.appendContent(element, content

AviFlow.tools.element.appendContent(element, content) -> HTMLElement | null

Adds content after existing children, never touching the element value.
