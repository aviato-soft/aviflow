Demonstrating data-flow attribute handling with missing optional parameters

data-flow="input -> transformText -> #output-1"

2. Default Event (Click): Action -> Target

data-flow="generateTimestamp -> #output-2"

3. Action Only (Default Event: Click, No Target)
